# مدل‌های برنامه‌ریزی حمل‌ونقل

شش ماشین‌حساب تعاملی برای درس حمل‌ونقل، نوشته‌شده با HTML، CSS و JavaScript. رابط ماشین‌حساب‌ها انگلیسی است.

## اجرای پروژه

فایل `index.html` را در مرورگر باز کنید و یکی از مدل‌ها را انتخاب کنید. محاسبات در مرورگر انجام می‌شوند و نیازی به نصب بسته یا راه‌اندازی سرور ندارند.

## توزیع سفر

- [مدل جاذبه](models/gravity_model.html) — برآورد سفرهای بین نواحی با استفاده از تولید و جذب سفر و امپدانس سفر.
- [مدل فرنس](models/furness_model.html) — تعدیل ماتریس سفر سال پایه برای رسیدن به مجموع سفرهای تولیدی و جذبی هدف.

## انتخاب شیوهٔ سفر

- [مدل لاجیت](models/logit_model.html) — تبدیل مطلوبیت هر شیوهٔ سفر به احتمال انتخاب آن.
- [لاجیت چندگزینه‌ای افزایشی](models/multinomial_logit_model.html) — برآورد سهم جدید هر شیوهٔ سفر با استفاده از سهم اولیه و تغییر مطلوبیت.
- [مدل QRS](models/QRS_model.html) — برآورد سهم خودرو و حمل‌ونقل عمومی با توجه به زمان و هزینهٔ سفر.

## تخصیص سفر

- [مدل TRC](models/TRC_model.html) — محاسبهٔ سهم مسیرهای جایگزین و تعداد سفرهای تخصیص‌یافته به هر مسیر.
