Fratar (Furness) Model

A calculation tool for interzonal trip distribution using the Fratar method, displaying full step-by-step calculations in each iteration until growth factors converge to 1.

tᵢFᵢ · tᵢⱼFⱼ

= Tᵢⱼ
Fᵢ⁽ᵗ⁺¹⁾ = (Tᵢ⁰ × Fᵢ⁰) / Tᵢ⁽ᵗ⁾

1 Number of Zones

Specify the number of zones between which trips will be distributed (minimum 2, maximum 8 zones).

2 Zone Information

Enter the name, base total trips (Tᵢ⁰), and growth factor (Fᵢ⁰) for each zone.

3 Base Trip Matrix (tij)

Enter the number of trips between each pair of zones in the base year. Values are assumed symmetric for both directions.
